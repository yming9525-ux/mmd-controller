# MMD 控制器

给 mmd_tools 导入的 MMD 模型一键装上好用的控制器。手脚可以直接抓着拖，手指批量弯，表情用面板拖，姿势和动作跟 MMD 的 VPD / VMD 文件互通。

模型本身的骨骼从头到尾不修改，随时可以完整移除。

插件开发：蛙灾。代码由 AI 编程辅助完成。

---

## 环境

- Blender 5.0 以上
- [mmd_tools](https://github.com/UuuNyaa/blender_mmd_tools)（模型本来就是它导入的）

## 安装

> **别点绿色的 Code → Download ZIP**，那个是源码包，Blender 装不了，装完插件列表里什么都不显示。
> 去右边 **[Releases](../../releases)** 下载 `mmd_controller_v1044.zip`，那个才是安装包。

1. 从 Releases 下载 zip
2. Blender 偏好设置 → 插件 → 安装，选中 zip
3. 在列表里搜「MMD」，勾选启用

装过旧版的先禁用并删除旧版，不然会出两套面板。

## 两步开始

1. 选中模型的骨架
2. N 面板 → MMD IK/FK → 生成骨骼系统

完事。MMD 原来那套足 IK 会自动接管，不用手动关。不想要了点「移除骨骼系统」，模型恢复原样。

生成完建议顺手校一次弯向，见下面「手肘膝盖弯错方向」。

## 控制器都是谁

| 长相 | 是谁 |
| --- | --- |
| 红色方块 / 脚形 | 手脚的 IK 目标，抓着拖，胳膊腿自己跟上 |
| 橙色球 | 手肘 / 膝盖的方向球，决定关节朝哪边弯 |
| 蓝绿色圆环 | FK 控制器，一节一节转关节用 |
| 黄色大圈 | 中心、上半身、头颈这些身体控制器 |
| 紫色球（手边） | BEND 手指球，整根手指一起弯 |
| 细圆环（手指上） | 手指单节微调 |

看不见控制器就去面板「控制器显示」里开，身体、手指手捩、手 FK、手 IK、脚 FK、脚 IK 六个开关分开管。

## 想做什么就看哪条

### 摆姿势

- 拖手脚：四肢切到 IK，抓红色目标拖，橙球调关节朝向
- 转关节：四肢切到 FK，转蓝绿圆环，一节一节来
- 移动整体：拖「全ての親」那个最大的圈。下蹲弯腰用「センター」和上半身的圈

### IK 和 FK 怎么切

面板「四肢 IK/FK 切换」里每条肢体一行：

- 滑条：左 FK 右 IK，拖到哪边就是哪边
- `⇄` 一键切到另一边，姿势不会跳
- `◆` 给这条肢体的当前控制器打关键帧

顶部「一键全部切换」是四条各自翻面。

### 手指

- 弯：转那颗 BEND 球，整根手指跟着弯
- 张开 / 并拢：选中 BEND 球按 <kbd>S</kbd> 缩放，放大张开、缩小并拢。四颗球一起框选一起缩最快
- 微调：转手指上的细圆环，一节一节调
- 方向不对：面板「手指弯曲方向」里改轴和正负

### 表情

独立面板「MMD 表情面板」→ 添加表情面板。眼睛十字框管眼神和眉毛，嘴巴五角星管 あいうえお 口型。

### 用现成的姿势卡（VPD）

- 导入 VPD 姿势 → 选文件 → 姿势直接上到控制器，继续改随意
- 导出 VPD 姿势 → 摆好 → 选保存位置

眼神不进控制器，眼睛由注视框管，导入后自己拖一下。

### 让模型跳舞（VMD）

- 导入 VMD 动作 → 选文件 → 等它逐帧转换，几千帧要一两分钟 → 播放。帧率和帧范围自动对到动作的 30fps
- 导出 VMD 动作 → 按场景帧范围自动烘焙写出，表情动画也带

做完记得检查场景帧率还是不是你想要的。

### 手肘膝盖弯错方向

面板「预弯曲」区，三步：

1. 点「自动弯一点 FK」，四肢各折 15°，弯向对错一眼看穿
2. 弯对了就点那条肢体的校准按钮，或者「校准全部」。校准完姿势自动归位
3. 弯错了先手动把手肘 / 膝盖那一节 FK 转到正确方向，再点校准

转的是手肘膝盖那一节，转大臂大腿没用。

### 其他

- 姿势全部归零：控制器、手指、所有姿势一键回默认站姿
- 做动画 K 帧：摆好一帧 → 每条肢体行尾的 `◆` 打关键帧 → 换帧继续。切换 IK/FK 的那一帧两边都 K 上

## 面板模块开关

偏好设置里可以单独显隐五个区块：姿态工具、预弯曲、四肢 IK/FK、手指弯曲方向、表情面板。后两个默认关闭。

## 出问题速查

| 症状 | 看这里 |
| --- | --- |
| 面板整个不见了 | 偏好设置 → 插件 → 本插件，模块开关是不是全关了 |
| 控制器不见了 | 面板「控制器显示」，六个开关挨个看 |
| 导入 VPD 眼神不对 | 正常，眼睛由注视框管，自己拖 |
| 下蹲时脚有点滑 | D 骨模型重新点一次「生成骨骼系统」，会自动加钉子 |
| VMD 导出后变速 | 场景帧率要是 30fps |
| 旧版预弯过的模型 | 直接生成就行，会自动识别不叠加 |
| 从旧版升级 | 重新点一次「生成骨骼系统」，刷新所有新功能 |
